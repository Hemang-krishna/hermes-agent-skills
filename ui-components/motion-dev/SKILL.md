# Motion (Framer Motion) Skill

## Overview
Motion (formerly Framer Motion) is the standard for web animations in React and Vanilla JS.

## Core Capabilities
1. **Animate Presets:** `initial`, `animate`, `exit`, `transition={{ duration: 0.3 }}`.
2. **Gestures:** `whileHover`, `whileTap`, `whileDrag`, `dragConstraints`.
3. **Layout Morphing:** `layoutId` for smooth transitions between pages or list items.

- Instruct Hermes: `"Animate this card list with Motion layout morphing on click."`
