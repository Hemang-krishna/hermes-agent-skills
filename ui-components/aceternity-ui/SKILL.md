# Aceternity UI Skill

## Overview
Aceternity UI offers copy-paste components built with Tailwind CSS, TypeScript, and Framer Motion.

## Popular Components
1. **Hero Blocks:** HeroHighlight, BackgroundBeams, Spotlight, TypewriterEffect.
2. **Cards & Hover:** BentoGrid, HoverEffect, 3DCardPin, GlareCard.
3. **Navigation & Modals:** FloatingNavbar, ExpandableTabs, AnimatedTooltip.

## Quick Pattern (Tailwind Bento Grid)
```html
<div class="grid grid-cols-1 md:grid-cols-3 gap-4">
  <div class="bg-slate-900 border border-slate-800 p-6 rounded-2xl hover:border-emerald-500 transition">
    <h3 class="text-lg font-bold text-white">Feature Item</h3>
  </div>
</div>
```
