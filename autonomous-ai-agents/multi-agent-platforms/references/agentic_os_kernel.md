# Agentic OS Kernel & Swarm Pipeline Reference

This reference documents the implementation architecture for `Hermes Agentic OS`, an operating kernel that parses, indexes, and orchestrates hundreds of specialized AI agent roles (such as `agency-agents-zh`).

---

## 1. Dynamic Markdown Agent Parser & Registry

When loading external agent libraries (e.g. 268 markdown files across 20+ department directories):

```python
class AgentSpec(BaseModel):
    id: str
    name: str
    department: str
    file_path: str
    description: str
    system_prompt: str
    tools_required: List[str]
    capabilities: List[str]
```

### Extraction Strategy:
1. **Name & Department:** Derived from directory structure (`<dept>/<agent_id>.md`) and markdown `# Title`.
2. **Role Description:** Extracted via regex over role summary sections (`角色描述`, `Overview`, `Identity`).
3. **Tool Inferences:** Automatically tags required tools (`terminal`, `file_io`, `python_interpreter`, `web_search`) based on keyword analysis of system prompt text.

## 2. Multi-Agent Swarm Handoff Pattern

```
[User Task Request] 
       │
       ▼
[Step 1: Agent A (Product Architect)] ──> Output A
       │
       ▼ (Append Output A to Prompt Context)
[Step 2: Agent B (Backend Developer)] ──> Output B
       │
       ▼ (Append Output A + B to Prompt Context)
[Step 3: Agent C (QA & Security Auditor)] ──> Final Aggregated Swarm Result
```

### Execution Implementation:
* **Context Accumulation:** Each agent receives the original global goal + all output text generated by preceding agents in the sequence.
* **State Immutability:** Step execution logs record step number, agent ID, input prompt snapshot, output deliverable, and wall-clock execution time.

## 3. Server Telemetry & Public Tunneling

* **Uvicorn Server Launcher:** Pass the exact virtualenv binary path (`/opt/venv/bin/python3 os_server.py`) when starting background processes.
* **Reverse Tunneling:** Expose local ports (`8080`) over HTTPS via SSH reverse tunnels:
  ```bash
  ssh -o StrictHostKeyChecking=no -o ServerAliveInterval=30 -R 80:localhost:8080 nokey@localhost.run
  ```
